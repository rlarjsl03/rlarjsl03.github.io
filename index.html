검색, 추천, 자동화, 생성형 AI가 일상의 여러 영역에서 실제로 사용되는 모습을 보며 관심을 갖게 되었습니다. 기술이 사람의 경험을 바꾸는 과정을 보면서 개념을 배우는 데서 그치지 않고 직접 구현해 보고 싶다는 목표가 구체화되었습니다.

Perspective

네트워크까지 보는 이유

Process

개발과 문제 해결 방식

Implementation

실제 코드에서 확인한 주요 구현

  • Canvas API로 입자와 연결선을 그리는 네트워크 배경
  • 스크롤 위치 기반 reveal과 진행 막대 업데이트

  • Pretext 동적 import와 실패 시 fallback 레이아웃
  • 패킷 경로·속도·시작 지점의 무작위 재설정
  • getBoundingClientRect() 기반 패킷·카드·문자 위치 계산
  • 패킷과 요소의 교차 및 근접 상태 판단
  • requestAnimationFrame() 기반 지속 상태 업데이트
  • 화면 resize 시 Canvas와 문자 레이아웃 재계산

Web_Project JavaScript

AI Model Booting 인터랙티브 자기소개

프로젝트 개요
웹프로그래밍 수업에서 진행한 개인 프로젝트입니다. AI 모델이 학습되고 네트워크를 거쳐 서비스로 배포되는 과정을 개인의 성장과 진로에 비유한 인터랙티브 자기소개 웹페이지로 기획했습니다.

기획 의도
자기소개 문장을 나열하는 대신 AI와 네트워크라는 관심 분야가 페이지의 구조와 상호작용에서도 드러나도록 구성했습니다. 학습 과정은 데이터셋으로, 진로는 라우팅 경로로, 앞으로의 계획은 배포 단계로 연결했습니다.

  • DATASET — AI에 관심을 갖게 된 과정과 학습 흐름을 AI Trend, Service, Network, Issue, Debug, Output의 데이터 단계로 표현했습니다.
  • PRETEXT NETWORK — @chenglou/pretext를 동적으로 불러와 자기소개 문장을 줄 단위로 배치하고, 각 문자를 개별 DOM 요소로 구성했습니다.
  • SYSTEM LOGS — 버튼을 선택하면 목표, 성장 과정, 문제 해결, 협업, 실패, 네트워크 이슈, 관심 기술, 직무 역량, 연구실 진학 방향에 맞춰 내용이 변경되도록 구현했습니다.
  • CAREER ROUTING MAP — 현재의 나에서 서비스 구조, 네트워크 연구, AI 시스템, AI 개발로 이어지는 진로를 라우팅 경로로 표현했습니다.
  • DEPLOY PLAN — 네트워크 기반 학습, AI 기술 학습, 프로젝트 경험을 실제 서비스 배포 단계처럼 순서대로 정리했습니다.

주요 구현
Canvas에 입자와 연결선을 그려 네트워크 배경을 만들고, 스크롤 위치에 따른 섹션 reveal과 진행 막대, 일정 간격으로 추가되는 부팅 로그를 구현했습니다. 패킷은 여러 경로 중 하나를 무작위로 선택하며 이동하고 애니메이션 반복 시 경로와 속도가 다시 설정됩니다.

JavaScript에서 getBoundingClientRect()로 패킷과 카드, 문자 영역의 위치를 계산하고 requestAnimationFrame()으로 교차 상태를 계속 확인했습니다. 패킷이 텍스트에 가까워지면 문자별 이동 값을 적용해 텍스트가 좌우로 피하도록 처리했으며, 화면 크기가 바뀔 때 Canvas와 Pretext 레이아웃도 다시 계산합니다.

사용 기술
HTML5 · CSS3 · Vanilla JavaScript · Canvas API · Pretext

배운 점
정적인 화면 구성에 그치지 않고 DOM 상태 변경, 요소 위치 계산, 사용자 입력에 따른 콘텐츠 전환, 애니메이션 상태 확인, 문자 단위 레이아웃 처리를 직접 구현했습니다. 기능이 많아질수록 데이터와 화면 상태를 작은 단위로 나누고 검증하는 과정이 중요하다는 점도 경험했습니다.
